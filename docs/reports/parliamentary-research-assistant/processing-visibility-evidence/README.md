# Processing-visibility evidence

These retained artifacts support
[`processing-visibility-and-outcomes.md`](../processing-visibility-and-outcomes.md).
They are observations from this implementation task, not human acceptance or
independent certification.

- `injected/`: deterministic injected-model and exact compiler-response replay.
  It includes plan-before-dispatch, slow-progress, failure/recovery, and browser
  summary evidence. It is not a configured-model run.
- `configured-r1/`: selected plan screenshot and a compact record of the
  configured R1 editorial attempt. The initial/revised prose is copied exactly
  from the retained live run; 49 to 41 words did not meet the 30% reduction
  acceptance check. This attempt stopped before a final-revision screenshot or
  the original verifier's Wexford leg.
- `configured-wexford/`: separate, fresh configured-model/read-only-Fuseki
  browser run of the frozen Wexford probe. It retains the full run archive and
  Markdown export, including unaccepted response envelopes, plus the plan and
  final-state screenshots and browser observations. Raw returned rows were not
  promoted into accepted research facts.

The frozen probe is not the unlocated originally reported Wexford question and
does not establish that question's original runtime cause. Artifacts contain
public parliamentary query results and model-generated drafts; no credentials
are retained.
