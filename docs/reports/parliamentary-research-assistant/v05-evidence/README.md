# v0.5 human-review evidence

**Research drafts, not independently accepted answers.** Parliamentary source
coverage and freshness are uncertified/unknown. No confidence calibration or
independent editorial acceptance is claimed.

## Evidence categories

- `research-review-bundle.json`: actual configured LLM and read-only Fuseki
  session. Contains original dialogue, model proposals and authorship outputs,
  exact fact-handle maps, report snapshots, assertion classes/reasoning/confidence,
  full accepted evidence and every actual query trace. Snapshots reference the
  shared final fact registry; all previous evidence remains retained.
- `r1-initial.md`, `r1-revision.md`, `r3-same-session.md`: human-reading copies of
  actual generated report bodies. Only the large technical JSON appendices are
  relocated to the review bundle; draft status, class labels, uncertainty,
  unanswered questions and assertion IDs are unchanged. These are not manually
  rewritten or fixed-template reports. The browser verifier also saves full
  Markdown exports in its output directory.
- `full-r3-export.md`: exact complete Markdown response from the export endpoint,
  including the retained Bill research, new career section, qualifications,
  assertion metadata and source/query appendices.
- `screenshots/`: browser observations of actual model-generated research,
  planning, assertion inspection, revision and responsive/zoom-equivalent views.
- `browser-summary.json`: configured browser checks, not human acceptance.
- `injected-ui-summary.json`: **injected model + exact saved compiler-response
  replay**, testing pause/resume, pre-dispatch plan visibility, keyboard/modal
  focus and retention after an independent failure. Not actual-model research.
- `language-planning-only/`: actual model interpretations of the separately
  frozen, **AI-authored paraphrases and qualifiers**. No factual queries were
  dispatched in these controls. These earlier planning observations precede the
  final conversational-response metadata addition and are not full research or
  final-schema integration tests.
- `manifest.json`: source/configuration context and artefact hashes. The model
  identifier is the requested local configuration, not an independent attestation
  of the serving provider. There is no immutable dataset snapshot identity.

R1/R3/R4/R5 are unchanged user-supplied acceptance briefs. Scripted follow-ups
and the additional language controls are implementation-agent-authored inputs.
The actual research prose, interpretations and plans were generated by the
configured research model, not supplied as canned responses by the test.

## Suggested human review

Read the untouched original brief alongside each draft. Check research purpose,
missing conditions, usefulness, plain-English parliamentary language, exact
factual scope and the proportionality of provisional interpretations. Challenge
any unsupported relationship, invented explanation or misplaced confidence.
Inspect both conversation and report: process-only model messages are not
independently certified as free of hidden factual content. Do not equate a
successful compiler query or a reference with exhaustive satisfaction of a brief.

Use [the four-dimension completion record](../v05-implementation.md) and the
[acceptance contract](../../../specifications/parliamentary-research-assistant-acceptance.md).
